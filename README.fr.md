# Gaetan Pruvot

[English](README.md) · Français

Développeur freelance basé à Lyon (SigmaQuantSystems). Je conçois des applications web et mobiles fiables, qui fonctionnent hors ligne et gardent les données sous contrôle.

**Disponible pour des missions en full remote**, courtes ou longues.

## Ce que je fais

- Applications web en React, avec des API Node (Fastify, Express) et PostgreSQL
- Applications mobiles Android en Kotlin et Jetpack Compose, et en React Native
- Outils Python pour la donnée et l'automatisation
- Tests automatisés et intégration continue : tests unitaires, Cypress, Playwright, GitHub Actions
- Sécurité applicative : authentification, CSRF, cookies, gestion des secrets

## Projets en avant

**[Taskora](https://github.com/Gaetan-PRUVOT-SQS/Taskora)** : kanban open source auto-hébergé. React, TypeScript strict, Fastify, PostgreSQL, Docker. Pipeline de test complet avec un seuil de plus de 90 % de couverture de lignes imposé par la CI.

**[Vida](https://vidapma.fr)** : site vitrine, en ligne à vidapma.fr, de l'application Android Vida de suivi de cycle et de parcours PMA. L'app garde les données locales et ne demande aucune connexion. Le dépôt [Vida.app](https://github.com/Gaetan-PRUVOT-SQS/Vida.app) contient le site, le code de l'application reste privé.

**[Kasa](https://github.com/Gaetan-PRUVOT-SQS/Kasa)** : location de logements entre particuliers en TypeScript strict, avec 100 % de couverture de tests, des tests de bout en bout et une CI.

**[i686-elf-gcc](https://github.com/Gaetan-PRUVOT-SQS/i686-elf-gcc)** : cross-compilateurs GCC i686-elf et x86_64-elf prêts à l'emploi pour le développement d'OS, construits et publiés par la CI, avec des noyaux de contrôle QEMU.
